# AI photo prompts for every menu item

One prompt per item, ready to paste into ChatGPT, Google Gemini, Adobe Firefly or Midjourney.
Every prompt uses the same style wording, so the photos look like one set. On GitHub, each grey box has a copy button in its top-right corner.

**How to use them**

1. Copy a prompt and paste it into the image tool.
2. Check the result against the real thing. AI tools are trained mostly on American food and often get Australian items wrong (potato scallops, dim sims, Chiko Rolls, "the lot"). Regenerate or ask it to fix specific things ("make the batter thicker", "remove the sesame seeds").
3. Save it with the file name shown under the item (e.g. `cod-fish.png`), so it replaces the right photo.
4. Send the photos to Claude, or run `python3 scripts/menu_photos.py <photos>` yourself (see the README).

**Better:** take a quick phone photo of the real item, upload it to the tool with the prompt, and add: *"Use the attached photo as the reference: keep the food exactly as it is, same portion and items, only improve the lighting, background and angle."* That way the photo matches what customers actually get.

Items marked ⚠ need a quick check against how the shop actually makes them.

Chips, gravy and fried rice don't show photos on the current menu design, so they aren't listed.
