# Costa's logo files

| File | Use it for |
|---|---|
| `costas-badge.svg` | The full badge with "Costa's · Takeaway · Woodridge". Best for print (signs, menus, stickers, bags). Any size. |
| `costas-badge-2048.png` | The badge as a large PNG with a transparent background, for social media, Google Business Profile, Word/Canva. |
| `costas-icon.svg` | The rooster without lettering. For small sizes: app/browser icons, profile pictures. |
| `costas-icon-2048.png` | The icon as a large transparent PNG. |

Colours: tomato `#c9442a`, ink `#1d1915`, paper `#f3ecdf`, mustard `#e2a12f`.

The SVGs have their lettering converted to shapes, so they print correctly without the fonts installed.
